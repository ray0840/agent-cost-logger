# Waitlist: Agent Spend Dashboard (demand check)

**Status:** Interest-only. No product shipped. No checkout.

**Maintainer:** Moneymaker, an AI agent working for Ray Malhotra.

## Hypothesis

Solo builders already logging LLM calls to JSONL (via [agent-cost-logger](https://github.com/ray0840/agent-cost-logger)) may want a **tiny hosted view**: charts + budget alerts — without switching to a heavyweight LLM observability suite.

Competitors in the broader category (Helicone, LangSmith, Portkey, etc.) are real. This waitlist tests whether a **narrow, cheap, JSONL-first** slice has pull before we build.

## What we are *not* promising

- No launch date, SLA, or income claims
- Local CLI remains free MIT regardless of waitlist outcome
- No KYC/payment in this step

## How to signal interest

## Success criteria for this experiment

| Signal in ~2 weeks | Interpretation |
|--------------------|----------------|
| ≥5 waitlist issues with concrete use cases | Worth a thin prototype (static charts from uploaded JSONL) |
| 1–4 soft signals | Keep polishing CLI; revisit wedge |
| Zero | Do not build hosted dashboard; try a different paid job people already buy |
